# Cursor Agent Instructions

## Project Setup Guidelines

When working on a new or empty repository:

1. **Always start by checking the project structure**
   - Look for `package.json`, `tsconfig.json`, and other configuration files
   - Identify the project type (React Native, Expo, Node.js, etc.)

2. **If the repository is empty:**
   - Create a basic `package.json` with appropriate dependencies
   - Set up the project structure based on the project type
   - Install dependencies

3. **Never stop working without:**
   - Completing the requested task
   - Explaining what was done
   - Asking for clarification only if truly needed

4. **Communication:**
   - Respond in Arabic when the user communicates in Arabic
   - Be proactive and helpful
