## Privacy Policy

SnapHandover is an offline-first job documentation application. The current release does not require an account and does not include advertising, analytics, tracking SDKs, payments, or cloud synchronization.

### Data stored on the device

The application can store job details, customer details, addresses, references, dates, descriptions, checklists, photos, notes, business information, logos, signatures, language settings, and locally generated PDF reports in its private application storage.

The application can also retain old ClipMaster clipboard history when that information already existed on the device before the update. Android backup is disabled for this release.

### Camera, photos, and timestamps

Camera access is requested only when the user chooses to take a job photo. The system photo picker is opened only when the user chooses an existing image. SnapHandover does not capture photos in the background.

Camera photos use the device time. For images selected from the photo library, original metadata is used when available. When original metadata is unavailable, the report identifies the image as a library image and shows the time it was added. Device times and photo metadata are documentation and are not independent verification.

### PDF reports and sharing

PDF reports are generated locally on the device. A report leaves the application only when the user deliberately selects another application or recipient through the operating system share sheet.

After a file has been shared, the privacy practices of the receiving email, messaging, storage, printing, or other third-party service apply.

### Network transmission and third parties

The current application code does not transmit jobs, photos, clipboard history, signatures, or PDF reports to the developer or to a third-party server. It contains no advertising, analytics, tracking, or payment SDK.

### Retention and deletion

Information remains on the device until the user removes it, selects **Delete all local data** from the in-app **Legal & privacy** screen, or uninstalls the application.

Deleting all local data removes SnapHandover jobs, original photos, previews, reports, settings, signatures, recovery data, and old ClipMaster clipboard history from that device. Copies previously shared with other applications or recipients are not deleted.

### Security and limitations

Application-private storage reduces access by ordinary applications, but no mobile device can be guaranteed completely secure.

A PDF, device timestamp, imported image metadata, or in-app signature is documentation. SnapHandover does not independently verify identity, consent, ownership, work quality, time accuracy, or legal admissibility.

### Children

SnapHandover is a business productivity tool and is not directed to children.

### Changes to this policy

This policy will be updated before the application introduces cloud synchronization, accounts, payments, analytics, advertising, or other processing that materially changes these practices.
